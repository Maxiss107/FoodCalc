# StudyHub — Многофункциональный веб-сервис для автоматизации учебы

**StudyHub** — это единая цифровая среда для студентов и исследователей, которая объединяет в одном рабочем пространстве интерактивное конспектирование, распознавание математических формул по фото и транскрибацию аудиозаписей. Главное отличие от аналогов — избавление пользователя от необходимости переключаться между узкопрофильными инструментами.

---

## 💡 Идея проекта
Создание умной цифровой среды для студентов технических и гуманитарных вузов, которая автоматизирует рутинные процессы: перенос формул с доски/тетради, расшифровку аудиолекций и структурирование знаний.

* **Тип проекта:** Веб-сервис с микросервисной ИИ-архитектурой.

---

## 🎯 Цель и задачи

### Цель проекта
Разработать веб-сервис для создания, хранения, обработки учебных конспектов с возможностью интеграции аудио - и графического контента.

### Основные задачи 
1. **Реализация базового функционала:** Иерархической системы папок,инструменты для форматирования конспектов,импорт и экспорт конспектов (PDF/DOCX), быстрый шеринг, заметки.
2. **Интеграция компьютерного зрения:** Разработка модуля локального распознавания изображений для мгновенного перевода фотографий математического синтаксиса в код LaTeX.
3. **Обработка аудио лекций:** Перевод аудиозаписей в конспект, генерация таймлайнов и заголовков подтем конспекта.
---

## 🛠 Структурные части и технологии (Стек)

### 1. Интерфейс (Frontend)
* **React & React Router** — компонентная архитектура и навигация приложения.
* **Tiptap** — управляет структурой текста конспекта.
* **KaTeX** — рендеринг математических формул в реальном времени.
* **Tailwind CSS** — адаптивный и современный интерфейс.

### 2. Главный сервер (Backend Core)
* **Python & FastAPI** — асинхронный высокопроизводительный API-сервер.
* **PostgreSQL** — хранение структуры папок, конспектов, контекстных закладок.
* **Docker** — контейнеризация приложения.

### 3. Модуль оцифровки формул (AI-Pix2Tex)
* **pix2tex** — легковесная нейросетевая модель, оптимизированная для инференса на обычном CPU. Переводит фото формулы в валидный LaTeX-код.

### 4. Модуль перевода аудио лекций в конспект 
* **Celery & Redis** — распределенная очередь задач и брокер сообщений.
* **faster-whisper** — высокоточная транскрибация длинных аудиозаписей лекций.
* **Commercial LLM API** — ИИ-суммаризация, автоматическое выделение определений и генерация умных таймлайнов с привязкой к темам.
